# Luxury Cars Showcase

Vitrine interativa de carros de luxo desenvolvida com **HTML, CSS e JavaScript**.

## Funcionalidades

- Navegação entre veículos Porsche, BMW e Escalade
- Animação do veículo em destaque
- Informações de potência, cor, preço e quilometragem
- Layout com destaque visual e controles de navegação

## Executar

Abra `index.html` no navegador depois de baixar os arquivos do projeto.

## Estrutura

- `index.html` — página principal
- `style.css` — estilos
- `script.js` — interações
- `assets/` — imagens dos veículos

**Nota:** O arquivo de imagem `assets/Scaleide.png`, referenciado no JavaScript, não estava presente no ZIP original.

## Tecnologias

HTML5 · CSS3 · JavaScript
